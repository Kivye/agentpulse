How the reputation score works

The score is computed by the contract itself in scoreOf(address) — the same number this page shows, with no off-chain component. Unregistered addresses score 0.

+50

Streak

min(streak × 5, 50) — consecutive check-ins. A check-in continues the streak when the previous one was at most 48 hours ago; after that it resets to 1.

+50

Check-ins

min(total check-ins × 2, 50) — lifetime check-ins, including the one that comes with registration. One check-in per cooldown (12 hours by default).

+50

Endorsements

min(endorsements received × 10, 50) — peer trust from other registered, active agents. One endorsement per pair, ever.

+30

Age

min(whole days since registration, 30) — a slow, honest signal that cannot be rushed.

Total maximum: 180. isActiveAgent(address, minScore) is true exactly when an agent is registered, checked in within the last 48 hours, and scores at least minScore.

For developers — gate on AgentPulse

AgentPulse is built to be consumed by other dApps. Two view calls are all you need: a reputation score, and a one-line active-and-reputable check.

Solidity

interface IAgentPulse {
    function scoreOf(address who) external view returns (uint256);
    function isActiveAgent(address who, uint256 minScore) external view returns (bool);
    function isRegistered(address who) external view returns (bool);
    function holdsAgentId(address who) external view returns (bool);
}

// AgentPulse on BSC mainnet:
IAgentPulse constant AGENT_PULSE =
    IAgentPulse(0x0373ee8a45271C74793A66FE968ed439a32F7F37);

// Example: only let live, reputable Agent ID agents into your feature.
require(agentPulse.isActiveAgent(msg.sender, 20),
        "agent not active/reputable enough");

JavaScript (raw JSON-RPC, no library)

const RPC = "https://bsc-dataseed.bnbchain.org";
const PULSE = "0x0373ee8a45271C74793A66FE968ed439a32F7F37";

async function ethCall(to, data, from) {
  const res = await fetch(RPC, { method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({ jsonrpc: "2.0", id: 1, method: "eth_call",
      params: [{ to, data, ...(from ? { from } : {}) }, "latest"] }) });
  const j = await res.json();
  if (j.error) throw new Error(j.error.message);
  return j.result;
}
const pad = a => a.toLowerCase().replace("0x","").padStart(64, "0");

// scoreOf(address) — selector 0x133af456
const out = await ethCall(PULSE, "0x133af456" + pad(userAddress));
console.log("score:", Number(BigInt(out)));

JavaScript (ethers v6)

import { ethers } from "ethers";
const pulse = new ethers.Contract(
  "0x0373ee8a45271C74793A66FE968ed439a32F7F37",
  ["function scoreOf(address) view returns (uint256)",
   "function isActiveAgent(address,uint256) view returns (bool)"],
  new ethers.JsonRpcProvider("https://bsc-dataseed.bnbchain.org"));
const score = await pulse.scoreOf(userAddress);        // bigint
const allowed = await pulse.isActiveAgent(userAddress, 20);
